# Siya’s Physiotherapy & Rehabilitation Centre

A modern, responsive web application for **Siya’s Physiotherapy & Rehabilitation Centre**, featuring comprehensive clinic information, specialized treatment pages, clinical consultation booking, and interactive Google Maps integration.

---

## 🚀 Tech Stack

- **Framework:** React 18 (with TypeScript)
- **Bundler & Dev Server:** Vite 6
- **Routing:** React Router v6
- **Styling:** Tailwind CSS + PostCSS + CSS Animations
- **Icons:** Lucide React & Official Brand SVGs
- **Motion:** Framer Motion

---

## 📁 Key Features

- **5 Distinct Pages:**
  - `Home` (`/`): Clinic overview, clinical highlights, hero slider, and lead conversion.
  - `Treatments` (`/treatments`): Detailed physiotherapy modalities and rehabilitation programs.
  - `Specialist & About` (`/about`): Clinical credentials, qualifications, and philosophy of Dr. Alistair Wright.
  - `Recovery Stories` (`/stories`): Patient outcomes, testimonials, and video recovery case studies.
  - `Contact & Clinic` (`/contact`): Consultation request form, clinic hours, direct helpline desk, and location map.
- **Responsive Mobile Navigation:** Floating 5-item quick-action dock for mobile devices.
- **One-Click Clinical Connect:** Direct telephonic desk and official WhatsApp connectivity.
- **Dynamic Consultation Booking Modal:** Form validation and WhatsApp instant confirmation.

## 🛠️ Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/healthyufitnessstudio2-boop/Riya-s.git

# Navigate into the project directory
cd Riya-s

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Production Build

```bash
# Compile and bundle for production
npm run build

# Preview production build locally
npm run preview
```
